1️⃣ Manage Collections (Add / Edit / Delete)

PROMPT – Create Collection Management System

Create a full collection management system for my Next.js ecommerce site.

Create database model:

Collection:

id

title

slug

subtitle

description

imageUrl

isFeatured (boolean)

displayOrder (number)

createdAt

Create admin routes:

/admin/collections

Add new collection

Edit collection

Delete collection

Reorder collections

Create API routes:

GET /api/admin/collections

POST /api/admin/collections

PUT /api/admin/collections/:id

DELETE /api/admin/collections/:id

Only allow admin role access.

On frontend homepage:

Fetch collections dynamically

Display in "Collections" section

Sort by displayOrder

Do not hardcode any collection data.

2️⃣ Manage "New Arrivals" Section

Instead of manually marking products, let admin control it.

PROMPT – Create New Arrivals Management

Create admin feature to manage New Arrivals section.

Option 1:
Add field to Product model:

isNewArrival (boolean)

OR

Option 2 (better):
Create separate NewArrival model:

NewArrival:

productId

displayOrder

createdAt

Create:

/admin/new-arrivals page

Add product to New Arrivals

Remove product

Change display order

Homepage should:

Fetch products dynamically marked as New Arrival

Sort by displayOrder

Limit to 4 or 8 products

Only admin can manage.

ZayelleEdit:

id

title (optional)

subtitle (optional)

displayOrder

createdAt

Create admin page:

/admin/zayelle-edit

Upload image

Add title

Add redirect link

Change display order

Delete item

On homepage:

Fetch dynamically

Render grid layout

Sort by displayOrder

Only admin can access this.

Banner:

7️⃣ Drag & Drop Section Ordering (Advanced Feature)

If you want Shopify-level control.

PROMPT – Create Dynamic Homepage Section Order

Create a section management system.

Create model:

HomepageSection:

id

sectionName (collections, new-arrivals, zayelle-edit, banners, etc.)

isVisible (boolean)

displayOrder (number)

Admin page:

/admin/homepage-layout

Toggle visibility

Change section order (drag and drop)

Save layout

Homepage:

Render sections dynamically based on:

isVisible

displayOrder

No section order should be hardcoded.
